# WF-604 Operator UI Contract

## Version history

- 1.0.0 (2026-08-23): Initial governance UI.

The operator view lists canonical ID, current state, data age/quality, drift, methodology/definition versions, current flags and deployment eligibility. A transition drawer shows permitted next states, consequence, required reason and evidence ID, actor identity, approval requirement and immutable history. Pausing prominently states “stops new sandbox deployment; historical evidence is retained.” Retire and quarantine require explicit confirmation; retired is terminal.
