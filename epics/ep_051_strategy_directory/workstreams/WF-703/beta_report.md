# WF-703 Private-beta Evidence Review

## Version history

- 1.0.0 (2026-08-23): Initial controlled beta-readiness review.

The controlled cohort package targets research analysts, portfolio decision-makers, operations reviewers and informed non-specialist users. Invitations must state research-only scope, no personalised advice, no live broker connection, session recording/feedback consent and the tasks below. No invitations were externally sent by this implementation task.

Journeys: find a strategy from 300–500 entries; explain metric source/sample/window/limitations; distinguish target-reached from outcome; compare only compatible evidence; explain why a portfolio candidate and exclusions appeared; identify open state as separate; save/share without private data. Success requires ≥80% unaided journey completion and ≥80% correct explanation of evidence, compatibility, historical limitation and portfolio rationale, with zero material private-data or “guaranteed return” interpretation.

Internal controlled evidence review passed all six automated comprehension-presence checks and the Chrome/Firefox journeys from WF-701. Material trust issues discovered during review—open-state ownership, optimizer abuse bounds, non-finite safety inputs and timestamp integrity—were resolved in WF-702. This proves the beta package and interface explanations are ready; external participant results must be appended before claiming real-market comprehension.
