# WF-301 Discovery Contract

Default sort is explicitly `strategy_id ascending`; there is no opaque “best” rank. Evidence filters cover market, minimum trades/history, monetary return/basis, win rate, profit factor, maximum monetary drawdown, direction, activity, holding period and governed score bands. URLs encode filters/sort/page and can be copied. Compare selection is keyboard-accessible and capped with an explanation. Cards/rows show sample, window, freshness, methodology and quality. Loading, empty, stale, insufficient and error states have distinct copy and recovery actions.

Browser journeys: filter to qualifying strategies; change sort; select compare; copy shareable URL; clear zero-result state; inspect stale/insufficient badges; verify 390px responsive layout and semantic controls.
