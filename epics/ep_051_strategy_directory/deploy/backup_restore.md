# EP051 Backup and Restore

Version 1.0.0 — 2026-08-23

Before promotion, create an encrypted platform database backup plus the application evidence archive generated by `python deploy/release/backup.py <explicit-external-path>`. Record its SHA-256 in the change record. The helper refuses destinations inside the source tree and never captures credentials.

Restore only into an empty isolated validation environment: verify the archive hash and safe member paths, restore database with a read-only validation identity, run migrations in status mode, execute CI/data-quality/reconciliation checks, compare row counts and snapshot IDs, then obtain operator approval. Never overwrite production directly. Database restoration uses the platform's audited backup facility; this repository intentionally contains no production credential or destructive restore command.
