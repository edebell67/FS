Two areas are formally outstanding and deliberately excluded from this pass: the site generation module (black box — must be model-agnostic, reused for both first build and applying owner-requested changes) and the payment module (activation is a payment event, needs a provider, checkout links and a signature-verified webhook). Everything on either side of both has been built against a fixed interface so neither blocks the rest.

Evidence standard used here: "Complete" means live-verified — a real database query, a real HTTP call, or a real email received. Code that only typechecks and passes source-assertion tests is capped below 100%.
