The generation step itself is deliberately captured as a black box -- model-agnostic, to be resolved and plugged in later as a modular inclusion. Scope for this pass: every node except the black box is real, buildable work with a clean interface on both sides of it. The black box's contract: given a business's data, produce a real site and return its URL (or fail) -- how it does that is deliberately out of scope right now.
