Assistant engagement

On-demand: the assistant waits for the visitor to open the widget (current default). Proactive: the assistant opens itself and offers help on every page visit. If a visitor declines the proactive prompt, it automatically falls back to on-demand for the rest of that visit.

Visitor analytics

Log anonymous visitor behaviour (unique visits and timing, pages, clicks) for the Visitor insights view. No visitor is identified — an ephemeral per-visit id only, no persistent tracking or PII. Switch off per site to stop logging entirely.

Brand system

Enabled modules

The core assistant is always enabled. Every other capability can operate independently.

Lead follow-up (retention)

When Lead follow-up is enabled above, any lead that doesn't convert in the same chat gets an automatic re-notification to your team after this delay, so it doesn't go cold. Average job value is used only to estimate recovered revenue on the ROI page.
